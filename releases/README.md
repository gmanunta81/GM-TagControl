# Releases

This folder contains the ready-to-import solution packages:

| File | Type | Use |
|---|---|---|
| `GMTagControl_1.0.3.0_managed.zip` | Managed | Production / test environments (recommended) |
| `GMTagControl_1.0.3.0_unmanaged.zip` | Unmanaged | Development environments |

The same files are attached to the GitHub Release `v1.0.3`:
`https://github.com/gmanunta81/GM-TagControl/releases`

Do not mix managed and unmanaged installs of the same solution in one environment.
To rebuild locally see the *Deploy* section in the root README.
